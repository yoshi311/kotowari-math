# コトワリの旅 ― 数理の灯をともせ

公式の「意味」と「使いどころ」から学ぶ、高校数学（数学Ⅰ・A／Ⅱ・B・C）の冒険型学習Webアプリ。
初学者向けに、小学校高学年でもわかる言葉で説明しつつ、最終的に共通テスト9割を目指す。

## 使い方

```bash
npm install
npm run dev      # 開発用サーバー（http://localhost:5173）
npm test         # 答え合わせ・問題生成・教材データのテスト
npm run build    # 本番ビルド（dist/）
```

## 1レッスンの流れ

1. **なぞ** … 物語の中で、実生活の困りごとが起きる
2. **さわって発見** … 動かせる図で、自分で法則に気づく
3. **ことばにする** … 「この公式は◯◯を求める道具」＋たとえ話
4. **どこで使われている？** … 実生活・科学・技術での活用例
5. **練習** … 意味 → 計算 → 共通テスト風（マーク式）。間違えるとカイの失敗例とヒント
6. **理術カード獲得** … 図鑑に登録

## フォルダ構成

| 場所 | 中身 |
|---|---|
| `src/content/` | 教材データ（レッスン・問題・カード）。**新しい単元はここにデータを足すだけ** |
| `src/content/generators/` | 数値を変えて何度でも出せる問題 |
| `src/engine/` | 式の同値判定（`poly.ts`）、答え合わせ、間隔反復、進行状況の保存、効果音 |
| `src/components/figures/` | 動かせる図（面積タイル・料金の箱・同類項タイル・指数ブロック・暗算） |
| `src/components/story/` | キャラクター・背景（すべて自作SVG）、会話 |
| `src/screens/` | ホーム・レッスン・復習・図鑑・記録 |

## レッスンの追加方法

1. `src/content/math1/suu-to-shiki/lesson04.ts` のようにファイルを作る（`lesson03.ts` が見本）
2. 同じフォルダの `index.ts` の `lessons` に追加し、`upcoming` から外す
3. `npm test` で、正解データの書きまちがい・ID の重複などを自動チェック

## GitHub Pages で公開

1. GitHub にリポジトリを作り、このフォルダを `main` ブランチに push
2. リポジトリの **Settings → Pages → Source** を **GitHub Actions** にする
3. 以後は push するたびに `.github/workflows/deploy.yml` が自動でテスト・ビルド・公開する

`vite.config.ts` は `base: './'`、画面遷移はハッシュ方式なので、リポジトリ名に関係なくそのまま動く。
学習記録は各端末のブラウザ（localStorage）に保存される。
